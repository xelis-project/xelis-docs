Inclusion does not constitute an endorsement.
The ecosystem changes frequently, so please report outdated links or suggest additions through the [XELIS community](/links/community).

## Applications

Applications are software programs that run on the XELIS network, including wallets, exchanges, and other tools for interacting with the blockchain.

## Mining

Mining is the process of validating transactions and adding them to the blockchain. It is also how new XELIS coins are created.

<Cards>
  <Card title="Rigel Miner" href="https://github.com/rigelminer/rigel" subtitle="A third-party GPU miner with support for XELIS mining." />
  <Card title="OneZeroMiner" href="https://github.com/OneZeroMiner/onezerominer" subtitle="A third-party GPU miner with XELISHash support for Nvidia and AMD GPUs." />
